# IT-Eksamen
# Automatisert brukeradministrasjon i Active Directory

## Beskrivelse

Dette prosjektet automatiserer opprettelse, deaktivering og sletting av brukerkontoer i Active Directory ved hjelp av PowerShell.

## Problem

Når elever starter eller slutter på skolen må brukerkontoer administreres manuelt. Dette er tidkrevende og kan føre til feil.

## Løsning

Et PowerShell-basert system som:

- Oppretter brukere fra CSV
- Deaktiverer brukere
- Flytter brukere til egen OU
- Logger alle handlinger
- Kan slette brukere etter en gitt periode
